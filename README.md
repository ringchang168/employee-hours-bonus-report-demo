# 員工工時與示範獎金報表自動化（公開展示版）

本專案使用**從零產生的虛構資料**，展示服務紀錄、工時分類、轉場與示範獎金報表的自動化流程。所有員工、地點、日期與金額皆為教學示例，不代表真實薪資或法定計算方式。

模擬輸入資料、計算程式、示範薪資單及 Excel 報表均已建立。公開前已檢查檔案內容，未納入課程原始檔或真實員工資料。

本次 2025 年 5 月示例包含 5 位虛構員工、85 筆服務紀錄；合計有效服務 517 小時、示範獎金 4,000 元、示範應發金額 111,800 元。這些數字僅供展示流程，不代表實際薪資。

## 資料檔

- `data/employees.csv`：5 位虛構員工及示範上班類型。
- `data/services.csv`：2025 年 5 月的虛構服務紀錄。`已簽退`列計入工時；`取消`列僅用於測試排除規則。
- `data/demo_calendar.csv`：專案自行指定的示範假日與補班日，**不是真實臺灣行事曆**。
- `output/示範員工工時與薪資報表.xlsx`：目前 2025 年 5 月的示範 Excel 成品，含總覽、薪資計算、薪資單、每日工時、規則與虛構紀錄。

重新產生資料：用可用的 Python 解譯器執行 `generate_demo_data.py`；再執行 `validate_demo_data.py` 檢查。產生程式僅寫入本資料夾的 `data` 子資料夾。

## 基礎計算

用可用的 Python 解譯器執行 `calculate_report.py`，可計算每位員工的服務時數、轉場分鐘、示範獎金與薪資分項；執行 `python -m unittest test_calculate_report.py` 可進行回歸測試。程式只讀取本資料夾 `data` 中的模擬資料，不寫入課程原始資料。

Excel 成品由 `build_salary_demo.mjs` 產生，需有 Node.js、Python 及 `@oai/artifact-tool` 環境。這份 Excel 的金額欄有公式，修改「示範規則」中的時薪、倍率或獎金門檻會更新金額；**若修改 CSV 紀錄，必須重新執行產生程式**，已存的 Excel 不會自行讀取 CSV。

已簽退的服務分鐘計入工時；取消紀錄不計入。每位員工每天按開始時間排序，相鄰服務地點不同則記一次 15 分鐘轉場。轉場分鐘另列，不併入服務時數或獎金門檻。

本作品**自行設定**示範日別：類型1為週一至週五的一般工作日、週末為休息日；類型2為週一至週六的一般工作日、週日為休息日。`demo_calendar.csv` 中的示範假日與補班日優先於上述星期規則。示範假日與休息日的服務分鐘各自列為一類；一般工作日的前 8 小時列為一般服務分鐘、接下來 2 小時及再接下來 2 小時各列一類。每日服務超過 12 小時會被拒絕。這是為了展示分類流程而設計的**模擬規則**，不是老師課程原規則，也不是法定加班或薪資計算。

## 示範薪資與獎金規則

每位員工在當月計入的服務時間達 **100 小時**，示範獎金為 **1,000 元**；未達則為 0 元。轉場分鐘不併入門檻。這是本作品自行設計的練習規則，並非課程原規格或實際薪資制度。

示範基本時薪為 **200 元**；一般服務倍率 1、平日延長前 2 小時倍率 1.25、後 2 小時倍率 1.5、休息日倍率 1.25、示範假日倍率 1.5、轉場倍率 1。每個分項金額四捨五入至整元再相加。Excel 中的「示範應發合計」尚未扣除保險、稅或其他項目，**不能作為實際薪資單使用**。

## 隱私與來源

本公開版不包含老師提供的原始服務紀錄、員工設定、範本、課堂筆記或操作手冊，也不使用真實姓名、身分證號、生日、地址。原始課程資料保留在原位置，不會被本專案修改。
